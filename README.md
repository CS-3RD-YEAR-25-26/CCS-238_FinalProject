# BASIC and Swift Program Examples

These are the six standalone source files used in the BASIC and Swift comparison.

| Program | BASIC | Swift | Sample input and result |
| --- | --- | --- | --- |
| Guessing game | [guessing_game.bas](basic/guessing_game.bas) | [guessing_game.swift](swift/guessing_game.swift) | Enter 3, 50, and 42 on separate lines to get Too low, Too high, and Correct! |
| Grade calculator | [grade_calculator.bas](basic/grade_calculator.bas) | [grade_calculator.swift](swift/grade_calculator.swift) | Enter Ana and 89 on separate lines to get Status: Passed. |
| Factorial calculator | [factorial_calculator.bas](basic/factorial_calculator.bas) | [factorial_calculator.swift](swift/factorial_calculator.swift) | Enter 5 to get Result: 120. |

Open and run one `.bas` file at a time in a QBasic-compatible environment such as QB64. With Swift installed, run one `.swift` file at a time from the extracted folder, for example:

```sh
swift swift/guessing_game.swift
```
